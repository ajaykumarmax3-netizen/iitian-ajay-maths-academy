Chapter 1: Sets and Functions

Study the basic concepts of sets, relations and functions. These are the building blocks for many topics in Algebra.

📘 Introduction

Sets and functions are fundamental concepts in mathematics. They provide the foundation for many areas of algebra and higher mathematics.

📌 Important Definitions

Set

A set is a well-defined collection of distinct objects.

Subset

A set A is called a subset of B if every element of A also belongs to B.

Empty Set

A set containing no elements is called an empty set.

🧮 Important Formulas

n(A ∪ B) = n(A) + n(B) − n(A ∩ B)

n(A') = n(U) − n(A)
