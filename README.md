# IITian Ajay Maths Academy — Free Website

## Free deployment
1. Create a GitHub account.
2. Create a repository named `iitian-ajay-maths-academy`.
3. Upload all files from this folder.
4. Open repository Settings → Pages.
5. Select the `main` branch and save.
6. GitHub will give you a free public website address.

## Adding new content
For the first free version, edit or add HTML pages through the GitHub website. A later CMS/Admin Dashboard can be connected, but it requires one-time GitHub authentication setup.

## Google Search
After the site is live:
1. Add it to Google Search Console.
2. Verify ownership.
3. Submit the sitemap when available.
4. Publish original, useful content regularly.

Important: Do not copy copyrighted book notes or solutions verbatim. Write explanations in your own words.
